## 維護規則

- 不得放入客戶資料、安裝檔、私鑰、授權碼、帳號密碼或未公開程式原始碼。
- 正式安裝檔發布前，Windows 必須確認 Authenticode 簽章；Google Play 必須使用正式受保護上傳金鑰建立 AAB。
- 稅務或法規資料更新只能在專業覆核後，以受簽章保護的資料包發布。
- 更新網站後，GitHub Pages 會由 `main` 分支根目錄重新發布。
