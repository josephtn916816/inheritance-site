發布與下載

目前最新驗收版本為 17.0.109。正式發行檔將透過官方 GitHub Releases 頁提供；下載前請核對版本、平台與簽章狀態。

正式下載準備中

Windows、Android 與 Apple 的驗收檔僅供內部測試，未上傳至此公開網站。正式版本完成簽章、平台審核與版本核對後，才會於官方 GitHub Releases 提供下載與 SHA-256 驗證資訊。

Windows 客戶版

供已授權客戶使用。正式對外版應具備有效的 Authenticode 簽章。

Windows 管理主控版

僅限內部營運，不可轉交客戶或公開下載。

Android 測試版

僅供驗收使用；完整工作台必須使用 adaptive／Play 分流。Debug APK 不會列為正式公開下載。

Google Play 商店版

將由 Google Play 的內部／封閉測試軌道開始發布；Debug AAB 不會上架。

Apple 客戶版

iPhone、iPad 與 macOS 客戶版已備妥 17.0.109／build 90 建置來源；IPA／DMG 必須由 Mac 與 Apple Developer 簽署後才可發布。

目前尚未發布正式安裝檔。Windows 商業簽章、Google Play 正式上傳金鑰與 Apple 簽署完成後，才會在此提供可對外下載的版本。
